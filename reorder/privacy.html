Privacy policy

Reorder Nudge · Last updated: 18 October 2026

This policy explains what data the Reorder Nudge app ("the app"), published by Nudge4 ("we", "us"), handles when a merchant installs it on a Shopify store.

Data the app reads from Shopify

  • B2B orders: order number, date, total, the purchasing company, company location and company contact (as IDs and company/location names), and the line items of a location's last order.
  • The app's own settings and fields (reorder interval, pause) and the store's time zone and plan.

The app does not read customer names, email addresses, phone numbers or addresses. Reorder emails are addressed and sent by Shopify (draft order invoices).

Data we store

  • The store's domain and an access token issued by Shopify, so automatic reminders can run while the merchant is away.
  • A send log: company location ID, order ID of the cycle, draft order ID, date and whether it was manual or automatic.

This is stored in a Cloudflare D1 database. Settings live in the merchant's own Shopify store (metafields).

Service providers

  • Shopify: the source of store data; sends the reorder emails.
  • Cloudflare (Workers, D1): runs the app's server code and stores the data listed above.
  • GitHub Pages: serves the app page's static files. No store data passes through it.

Retention and deletion

  • On uninstall (and on Shopify's shop/redact request) we delete the store's token and send log.
  • We hold no customer personal data, so customers/data_request and customers/redact requests have nothing to return or erase. They are acknowledged.

How data is used

Only to provide the app's features. We don't sell data, use it for advertising, or share it with third parties.
