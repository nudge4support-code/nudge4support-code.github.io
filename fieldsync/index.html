Field Sync and Rollups for Zoho CRM

Keep related records in sync and roll up totals onto parent records, with no code, on every Zoho CRM edition. Everything runs inside your own Zoho CRM. No data leaves Zoho.

How it works

After install you will see a Sync Rules tab (it may be under the "…" menu in the top bar). Each record in it is one rule. Rules run automatically when an Account, Contact or Deal is created or edited, right after you save a rule (so existing records are covered), and once a day.

Create a Copy Fields rule

Example: copy Account Billing City to every Contact's Mailing City.

FieldValue
Rule TypeCopy Fields
Parent ModuleAccounts
Child ModuleContacts
Lookup FieldAccount_Name (the field on the child that points to the parent)
Source FieldBilling_City (on the parent; several allowed, comma-separated)
Target FieldMailing_City (on the child, in the same order as Source)
Activeticked

Create a Rollup rule

Example: total of Closed Won deals on each Account.

Child ModuleDeals
Lookup FieldAccount_Name
Source FieldAmount (the child field to aggregate; leave empty for Count)
Target Fieldyour Account field, for example Annual_Revenue or a custom field
OperationSum, Count, Minimum, Maximum, Average or Latest Date
Filter Field / Filter ValueStage / Closed Won (optional)

Field names

Use API names, not labels. Find them in Setup → Developer Hub → APIs → API names, or in Setup → Modules and Fields → (module) → field.

Custom modules

For a custom module, also fill in Related List with the API name of the related list on the parent that shows the children. Custom modules are updated when a rule is saved and in the daily recalculation.

Limits

  • Up to 1,000 child records per parent in real time, and up to 2,000 parents per module in each recalculation.
  • Updates made by the extension do not trigger other workflows, which prevents loops.
  • Each rule's Last Run and Last Result fields show when it last ran.
