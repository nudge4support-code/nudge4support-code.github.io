Privacy policy

Code Blocks for Confluence · Last updated: 30 September 2026

This policy explains what data the Code Blocks app ("the app"), published by Nudge4 ("we"), handles when installed on an Atlassian Confluence Cloud site.

Where the app runs

The app is built on Atlassian Forge and runs entirely on Atlassian's infrastructure. It has no external servers, and it doesn't send data to us or to any third party. The syntax highlighter is bundled inside the app, so nothing is loaded from outside Atlassian.

Data the app handles

  • Code and block settings (title, language, tabs, highlighted lines and display options). These are saved inside the Confluence page where you insert the block, as part of the page content. They follow the page's permissions, version history and your site's data residency, like any other page content.
  • Licence status of your site, read from Atlassian when a block is shown, to decide whether highlighting is switched on.

Data the app stores

None. The app has no database or storage of its own. It does not store names, email addresses or Atlassian account IDs, and it uses no cookies, analytics or tracking.

Permissions

The app requests no Confluence permissions (scopes). It cannot read or change other pages, spaces or users.

Retention and deletion

Code lives in your pages. Editing the block, deleting it or deleting the page removes it, following Confluence's normal trash and version history. If the app is uninstalled, the code stays in the page content but is no longer displayed by the app.

Access

We have no access to your content. It stays in your Confluence site.
